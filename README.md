# UOAR_2
Repozitorijum za materijale iz kursa Uvod u organizaciju i arhitekturu racunara 2 za I - smer na Matematickom fakultetu

NAPOMENA: ako se bilo koji pdf ne otvara u okviru Github-a, samo ga lokalno preuzeti sa Github-a na Desktop ili bilo koji drugi direktorijum po zelji i onda ce biti dostupan za dalju upotrebu.

Linux OS: Ctrl + Alt + T => cd Desktop/ => git clone https://github.com/lukamijailovicmatf/UOAR_2.git.
Nakon komande "git clone https://github.com/lukamijailovicmatf/UOAR_2.git" iz terminala i njenog zavrsetka citav repozitorijum ce se nalaziti lokalno na Desktop-u i svi folderi / fajlovi / pdf-ovi ce biti dostupni za dalju upotrebu.
